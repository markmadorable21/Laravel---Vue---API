1. Open VS code
2. in terminal
  npm create vite@latest frontend (this will create new folder named frontent)
  select vue
  select JS
3. after install
  in terminal:
  npm install -D tailwindcss postcss autoprefixer
  npx tailwindcss init -p
  (see tailwind website to install tailwind since it was updated)


3. in another terminal
  laravel new backend (this will create new folder named backend)
  select vue
  select laravel
  select PHPUnit

4. to run frontend
  npm install
  npm run dev

5. to run backend
  php artisan serve

6. install for frontend
  npm install @headlessui/vue @heroicons/vue vue-router@v4 pinia axios
